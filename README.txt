How to open:
1. Unzip the whole folder first (do not open files from inside the zip).
2. Keep index.html, hero-form.html, support.js, image-slot.js and the assets folder together.
3. Double-click index.html or hero-form.html to open it in Chrome, Edge, Safari or Firefox.
4. An internet connection is needed (fonts and page engine load online).

Do not open the file in WhatsApp, email or phone file-preview; open it in a real browser.
To put it online, upload the whole folder to any web host (Netlify, Hostinger, cPanel etc.).
